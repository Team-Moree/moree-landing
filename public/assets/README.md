# Moree 랜딩페이지 이미지 에셋 (연결 완료)

모든 이미지는 투명 라운드 모서리를 가진 완성 그래픽(패널·폰프레임·카드 포함)이며,
아래 파일명으로 코드에 연결되어 있습니다. 같은 파일명으로 교체하면 코드 수정 없이 반영됩니다.

| 파일명 | 사용 위치 |
|---|---|
| `hero-phones.png`     | 히어로 — 지도+도감 폰 2개 |
| `mascot-surprised.png`| 페인포인트 — 놀란 몰리 |
| `solution-tags.png`   | "이제 Moree 하나면 충분해요" 좌측 — 카테고리 태그 + MOREE |
| `phone-map-green.png` | "이제 Moree 하나면 충분해요" 우측 — 초록 배경 지도 폰 |
| `mascot-mound.png`    | 초록 밴드 — 흙에서 나오는 몰리 |
| `phone-recommend.png` | 기능 — 내 취향에 맞는 행사 추천 |
| `phone-map.png`       | 기능 — 지도에서 한눈에 행사 찾기 |
| `phone-register.png`  | 기능 — 행사 등록도 간편하게 |
| `dogam.png`           | 기능 — 몰리로 채우는 덕질 도감 (카드 포함) |
| `phone-bookmark.png`  | 기능 — 나만의 덕질 활동 기록 |
| `app-icon.png`        | 하단 CTA 앱 아이콘 + **파비콘**(index.html) |
